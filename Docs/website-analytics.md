# Website analytics

Only `family.integ.life` loads the GA4 production web stream `G-1BT6RCD1CZ`.
Local and self-hosted copies do not load the Google tag. The five public route
names use a fixed product title and an empty referrer. Family names, member IDs,
recordings, transcripts, content, queries and tokens are not sent to Google.
Enhanced measurement and advertising signals are disabled. No backend storage
or media flow is changed by this frontend integration.
