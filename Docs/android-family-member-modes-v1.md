# Family Daily — Android 家庭成员模式 V1

> 日期：2026-08-22
> 状态：已实现并通过模拟器端到端验证

## 最小产品闭环

```text
打开 App
  ↓
选择当前家庭成员
  ↓
根据 member / elder / child 显示对应首屏
  ↓
普通成员处理家庭信息；老人语音记录；孩子听家庭故事
```

## 角色与界面

| 后端 `role` | App 模式 | V1 首屏重点 |
|---|---|---|
| `member` | 普通模式 | 照片备份、家庭问题、动态、为孩子生成故事 |
| `elder` | 老人模式 | 大按钮语音输入、最新 Family Daily |
| `child` | 孩子模式 | 阅读和播放家庭故事；也允许在共用手机上由大人生成 |

家庭成员列表由 `GET /api/v1/members` 读取。选中的成员 ID、名称和角色保存在 App 私有偏好中，重启后保持上次模式。如果成员已被删除，App 会回退到家庭成员列表中的第一人。

## 孩子故事

孩子不需要独立手机。在任意家庭共用的 Android 设备上，用户可以：

1. 切换到普通成员或孩子模式；
2. 在家庭中选择一个 `child` 成员；
3. 用当前 App 语言生成故事；
4. 阅读故事文字，或播放后端保存的音频。

后端会校验目标成员必须是 `child`，并且只使用 `visibility=family` 的家庭动态作为故事 Context。

## V1 信任边界

当前是“已进入同一家庭后的受信任身份切换”，不是完整登录系统。所有持有家庭 Token 的人都能切换家庭成员身份。因此 V1 适合家庭内共用设备和 PoC，不能用于强身份鉴别、儿童防护或私人数据授权。

## 验证

- Android 单元测覆盖三种角色的规范化和非法角色回退；
- Android Debug APK 可成功构建和安装；
- 模拟器实际验证普通、老人、孩子三种模式切换；
- 强制关闭并重启 App 后，孩子模式仍保持；
- 在 Android 界面生成故事，并通过故事音频 API 完成播放请求。
